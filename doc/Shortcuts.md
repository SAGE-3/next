# Shortcuts

| Command                  | Shortcut                                   | Note                                         |
| ------------------------ | ------------------------------------------ | -------------------------------------------- |
| **Pan**                      | Left click and Drag                        |                                              |
|                          | Spacebar + left click and drag             | when application filling screen              |
|                          | Arrow keys                                 |                                              |
| **Zoom**                     | Mouse wheel                                |                                              |
|                          | Spacebar + mouse wheel                     | when application filling screen              |
|                          | 2-finger scroll trackpad                   |                                              |
| **Select app**               | Left click over app window                 |                                              |
| **Deselect app**             | Left click on the board                    |                                              |
|                          | ESC key                                    |                                              |
| **Move app**                 | Left click over app and drag               |                                              |
| **Resize app**               | Left click side or corners app and drag    |                                              |
| **Zoom to app**              | Z key                                      |                                              |
| \- revert Zoom           | Shift + Z                                  |                                              |
| **Create stickie**           | Shift S                                    |                                              |
| **Multi-select apps**        | Shift + Left click and drag                |                                              |
| **Quick menu**               | Right click on the board                   |                                              |
| **Help**                     | ? key                                      |                                              |
| **Interaction modes**        | 1 — Lasso                                  | Select multiple apps                         |
|                          | 2 — Grab                                   | Pan the board                                |
|                          | 3 — Pen (Draw mode)                        | Freehand annotation                          |
|                          | 4 — Eraser                                 | Erase annotations                            |
|                          | ESC                                        | Deactivate / return to previous mode         |
| **Quickbar**                 | Cmd + K / Ctrl K                           | Commands and recent files                    |
|                          |                                            |                                              |
| **PDF**                      |                                            |                                              |
| Next page                | Arrow right, Arrow down                    |                                              |
| Previous page            | Arrow left, Arrow up                       |                                              |
| First page               | 1 key                                      |                                              |
| Last page                | 0 key                                      |                                              |
| Add a page               | \+ key                                     |                                              |
| Remove a page            | \- key                                     |                                              |
| **Stickie**                  |                                            |                                              |
| Shift-Tab                | opens another stickie                      | Opens to the right                           |
| Open from clipboard      | Paste text on the board                    |                                              |
| **SageCell**                 |                                            |                                              |
| Evaluate code            | Shift + Enter                              |                                              |
| Find                     | Cmd + F / Ctrl + F                         | also many Visual Studio Code shortcuts       |
| **Webview**                  |                                            |                                              |
| Open from desktop        | Drag URL from browser onto board           |                                              |
| Open from clipboard      | Paste URL on the board                     |                                              |
| Open a link from webview | Cmd + Click / Ctrl + Click                 | open link to the right of app                |
| **Open application**         |                                            |                                              |
| Application panel        | Click on application name                  | opens in center of viewport                  |
|                          | Click and drag application name            | opens at cursor location                     |
| **Asset manager**            | Double click on asset name                 | opens in center of viewport                  |
|                          | Click and drag asset name                  | opens at cursor location                     |
|                          | Select multiple item with Shift and drag   |                                              |
|                          | Select multiple item with Shift and delete | delete key                                   |
| **Upload file**              | Drag and drop form desktop                 | File open at drop location                   |
|                          | Click upload button in asset panel         | Can select folder                            |
| **Quick menu**               | Right click on board                       | Jupyter, cell, screenshare, stickie, webview |
